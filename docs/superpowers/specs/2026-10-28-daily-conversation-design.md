# 每日临时会话 / Daily temporary conversation

状态：用户于 2026-10-28 确认设计及当前会话实施，并明确允许 Codex、Antigravity 后台创建、发送和删除，不要求打开会话页面。

## 意图与已确认的选择

在 AiUsageWidget 悬浮球内增加每日定时任务。在电脑本地时间每天 05:30，为所选的 Codex、Antigravity 各后台新建一个独立会话，发送固定消息“今日东京天气”，发送成功后等待 60 秒，再永久删除本次创建的会话。时间可修改，功能可关闭，两个软件分别可选。如果软件未运行，自动启动它。

用户已选择悬浮球内置定时，而不是 Windows 计划任务。任务仅在悬浮球运行期间调度；不安装系统服务、不唤醒电脑、不绕过登录或解锁屏幕。使用现有 WPF/.NET 9 工程和本机已登录的软件，不引入另外的付费 API。

## 方案比较

1. **悬浮球内置调度（用户选择）**：复用设置存储和后台生命周期，容易开关和查看结果；退出悬浮球后不再触发新任务。
2. **Windows 计划任务（未选）**：能够在悬浮球退出后启动执行器，但需要额外安装、卸载和系统任务管理，仍不能在关机时执行。

会话操作优先使用本机可验证的会话接口及精确 ID，不采用屏幕坐标点击、按“最新会话”删除或直接修改对方数据库。Codex 已有会话 ID 删除能力；Antigravity 的创建、显示、发送和删除链路仍需兼容性验证，不能把尚未验证的内部接口当作可用功能交付。

## 设置与默认值（实现方建议，供确认）

- 新增“每日临时会话”区域，与用量展示开关独立。
- 总开关：初次升级默认关闭，避免升级后未经启用就开始发送和删除。
- 每日时间：默认 `05:30`，使用 `HH:mm`，按电脑当前本地时区运行。
- 软件：Codex、Antigravity 独立复选框，初始均选中；总开关开启时至少选一个。
- 消息固定为“今日东京天气”；删除等待固定为发送成功后的 60 秒。本次不增加任意提示词编辑器或复杂日历。
- 显示下次执行时间、各软件最近执行结果；提供“立即测试”，明确提示将实际创建、发送并删除临时会话。
- 中英双语标签、错误信息及 README 说明跟随现有项目风格。设置区域可滚动，不能挤掉现有保存、取消按钮。

## 调度与恢复规则

调度服务独立于用量刷新，不阻塞 WPF UI。使用可注入的时钟和两个软件适配器，便于测试，不依靠长时间阻塞等待。

1. 在目标分钟内检查是否应执行，例如 `05:30:00–05:30:59`；同一软件、同一本地日期最多自动尝试一次。
2. 先持久化当天的执行占位，再启动软件或创建会话。失败、计时器重入、重启和修改时间都不能让当天自动重复发送。手动测试单独记录，不占用每日执行次数，也不能与同一软件的在途任务并发。
3. 软件未运行时定位并启动已安装的正常桌面入口；等待就绪有明确超时。遇到未安装、未登录、接口不兼容或锁屏限制，报告原因，不能自动登录、代为确认权限或向当前已有会话发送消息。
4. 新建会话后，立即持久化供应商、精确会话 ID、创建时间和任务所有权；只在这条记录成功保存后发送消息。发送确认成功时记录删除到期时间，正常运行时至少等待 60 秒。
5. 不等待天气回答完成才开始 60 秒计时；清理时如仍在生成，先按同一会话 ID 终止生成，再删除。
6. 退出、关机、休眠或超过目标分钟才打开悬浮球，不补发错过的任务。退出后无法保证准时清理；下次启动根据持久化记录清理已到期临时会话，不重新发送。
7. 关闭总开关只阻止新的创建；已创建的会话仍执行原定清理，设置中明确说明。保存新时间不立刻补跑。
8. 多个软件互不影响：一个失败不阻止另一个。清理失败保留待处理记录并显示错误，有限次数退避重试；不能把失败标为已删除。

## 会话与删除安全边界

- 新建的是对应软件存储的独立会话。用户明确允许后台创建、发送和删除，无需打开会话页面或新建操作系统窗口；不能用无会话记录的纯模型请求替代。
- 只允许适配器返回、且本工具已持久化为自己创建的精确 ID 进入清理队列。禁止 `--last`、按名称模糊匹配、侧栏位置、最近修改时间或当前焦点来确定删除对象。
- 不能删除任何已有会话、项目、文件、其他任务或用户在临时会话中后来添加的内容。删除前确认身份，并检查是否出现额外用户消息；若无法确认安全或发现人工接管，则保留会话并显示“已跳过清理”。
- 不使用全局键盘输入或覆盖用户剪贴板来发消息，避免抢焦点后误发到其他窗口。自动打开软件可能切换前台，启用时明确提示。
- 日志不记录凭据、授权头、完整会话内容；仅记录必要的任务状态和诊断原因。执行记录与 widget 设置一样原子写入本机 `%LOCALAPPDATA%\AiUsageWidget`。
- 永久删除不同于归档。若某个软件版本只支持安全归档而不支持删除，必须明确报不兼容，不能无声替换行为或启用不可靠的删除兜底。

## 组件边界

- **设置模型及存储**：启用、时间、软件选择的默认值、验证、向后兼容和本地化。
- **调度与执行状态机**：日期去重、并发保护、启动恢复、发送后计时、清理重试和状态通知；所有外部操作异步且有超时。
- **执行记录存储**：独立保存每日占位、所有权、发送结果、待清理 ID、清理结果；损坏记录不得触发猜测性删除。
- **软件适配器**：分别完成检测/启动、创建并打开新会话、发送确认、确认未被用户接管、停止生成和精确删除；不读写对方的会话数据库来实现删除。
- **WPF 集成**：应用加载后启动调度，退出时停止新操作并保存状态；设置中显示状态及可手动测试。

实现者可决定内部类名、短轮询间隔、超时时长、有限重试间隔及适配器的具体协议，但不能放宽以上安全边界。必须先完成两种软件的后台新会话与精确清理验证，再声称完整支持。

## 验收与不做的事情

自动化测试覆盖：旧设置升级默认关闭、非法时间、未选软件、到点/跨日/错过时间、时钟回拨、重入、重启去重、单软件失败隔离、发送失败、60 秒边界、关闭后清理、待清理恢复、写盘失败、损坏记录、人工接管及清理失败重试。

集成验证需在当前已安装的 Codex 和 Antigravity 上分别创建专用测试会话，确认只发送一次、可见、等待满 60 秒、删除精确 ID，以及已有会话不受影响；锁屏或接口变动时必须安全失败。测试不得使用或删除用户原有会话。

不改变用量统计算法、不增加 7 天/30 天用量、不修改两个软件的模型或权限设置、不创建 Windows 计划任务、不保证关机/未登录桌面期间执行。删除会话不等于撤销已经消耗的额度；本功能会产生正常模型用量。
